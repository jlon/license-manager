# 阶段二：客户与授权核心流程升级需求

**状态：已确认（20260819）**

## 一、背景与目标

阶段一已完成社区版登录页、公共框架、首页看板和授权默认入口升级。当前客户与授权核心页面仍存在查询区结构不统一、表格依赖超宽布局、操作入口拥挤、详情信息层级不清、设备信息长文本难阅读、加载失败缺少页面内恢复入口等问题。

本阶段只升级社区版现有客户、授权和许可证设备相关页面的呈现与交互，不增加业务能力，不改变接口、数据结构、授权规则和许可证格式。

目标如下：

1. 统一客户与授权页面的标题、查询、列表、表单、详情和反馈规范。
2. 缩短从客户到授权、从授权列表到详情和设备信息的操作路径。
3. 改善许可证设备信息的可读性、操作反馈和窄屏可用性。
4. 清理针对单一分辨率的重复样式补丁，延续阶段一视觉基线。

## 二、功能范围

### 2.1 客户管理

- 统一客户列表的页面标题、主操作、查询条件、查询、重置、表格和分页布局。
- 保留客户类型、客户等级、状态和关键字等现有查询能力。
- 保留新增、查看授权、编辑、启用、禁用和删除操作。
- 优化操作列密度；常用操作直接可见，其余操作在窄屏下仍可稳定使用。
- 明确区分加载中、空数据、加载失败和正常数据，并为失败状态提供重试。
- 统一客户新增、编辑和详情页面的返回路径、信息分组、必填提示和提交反馈。
- 提交期间防止重复操作；启用、禁用和删除继续进行二次确认。

### 2.2 授权列表与客户筛选

- 授权管理继续默认进入全部授权列表。
- 在授权列表内提供现有客户筛选，并保留从客户页面带入客户条件的能力。
- 统一授权码、客户、状态等现有查询条件的查询和重置行为。
- 保留创建、查看详情、锁定、解锁和删除等现有操作及规则。
- 优化授权码、客户名称、日期、状态和操作列在常用桌面宽度下的展示。
- 表格窄屏时允许可控横向查看，不将字段压缩到不可读。
- 加载失败在列表区域内展示原因和重试，不只使用短暂消息提示。

### 2.3 授权创建与详情

- 授权创建表单按现有业务信息重新分组，不增加企业版字段。
- 必填项、日期范围、激活数量和配置输入的校验与帮助信息清晰。
- 详情页统一标题、授权码、状态、返回入口、主要操作和内容分区。
- 保留基础信息、授权信息、许可证信息和变更记录四个现有分区。
- 复制、更新、变更期限和下载等现有操作在桌面与窄屏下均可稳定使用。
- 危险操作明确指出影响对象，提交期间禁止重复点击。

### 2.4 许可证设备信息

- 保留社区版现有手动添加许可证设备、下载许可证和撤销许可证能力。
- 每台设备清晰展示在线状态、设备地址、最近活跃时间、硬件指纹、许可证编号和许可证状态。
- 长硬件指纹、许可证编号和地址不得撑破卡片；允许完整查看或复制关键值。
- 多设备场景下保持清晰分隔，单台设备的操作与状态不串行、不误触。
- 下载和撤销使用设备级独立加载状态，不阻塞其他设备查看。
- 撤销继续要求填写原因并二次确认，已撤销设备不能重复撤销。
- 添加设备弹窗在桌面和手机宽度下完整可用，校验、提交、取消和关闭行为一致。
- 补齐设备列表加载失败和重试状态；无设备时保留明确空状态和现有添加入口。

## 三、不在本阶段范围

- 不新增产品项、功能模板、设备台账或独立设备管理菜单。
- 不迁入企业版的设备选择、产品绑定、试用授权、激活后计时等能力。
- 不新增删除设备、批量设备操作或新的解绑接口。
- 不改变授权码、许可证、激活、心跳、下载和撤销的业务规则。
- 不新增后端接口，不修改现有接口响应结构，不执行数据库迁移。
- 不改造企业线索、发票和套餐页面；这些内容保留在阶段三。

## 四、验收标准

### 4.1 客户管理

- 查询、重置、分页和刷新后条件及结果符合现有规则。
- 客户列表在 1280×720、1366×768、1440×900 和 1920×1080 下不出现页面级横向溢出。
- 新增、编辑、详情、启禁用、删除和查看授权路径完整可用。
- 加载、空数据、失败和正常状态可以明确区分。

### 4.2 授权核心流程

- 从侧边栏进入授权管理时展示全部授权，并可按客户筛选。
- 从客户列表进入授权管理时自动带入对应客户条件，用户可清除或更换。
- 创建、查看、锁定、解锁、删除和下载的业务结果与升级前一致。
- 授权列表不依赖固定超宽尺寸；操作列在桌面与手机宽度下可使用。

### 4.3 设备信息

- 0 台、1 台和多台设备均有稳定布局。
- 超长硬件指纹、许可证编号和 IP 信息不遮挡状态和操作。
- 单台设备下载或撤销时，只显示该设备的进行中状态。
- 撤销失败后保留当前页面数据，并显示可理解的错误信息。
- 设备请求失败时可以在当前区域重试，不影响授权详情其他分区。

### 4.4 响应式、多语言与兼容性

- 中文、英文、日文下查询条件、按钮、状态和确认文案不重叠。
- 手机和平板宽度下，表单、详情分区、设备卡片和弹窗不被公共导航遮挡。
- 前端类型检查和生产构建通过。
- 不出现企业版专属字段、入口或接口调用。

## 五、实施顺序

1. 客户列表、客户表单和客户详情。
2. 授权列表与客户筛选。
3. 授权创建和授权详情公共结构。
4. 许可证设备信息、下载和撤销交互。
5. 三种语言、响应式和核心路径回归。
