# 社区版仪表盘业务数据升级交付

## 一句话总结

社区版仪表盘已按企业版业务分类升级为有效授权、设备激活、剩余名额、到期提醒、双业务趋势和最近记录，同时保留社区版视觉风格及雪松授权云推广区域。

## 交付清单

### 新增接口

- `GET /api/v1/dashboard/home`：返回首页概览、到期提醒、最近授权和最近激活。
- `GET /api/v1/dashboard/trends`：返回授权码创建趋势和许可证激活趋势，支持最近 7 天、最近 30 天和最长 365 天的自定义区间。

### 后端改动

- 新增仪表盘聚合和双趋势响应模型。
- 新增固定次数的概览、提醒、最近记录和趋势查询。
- 新增趋势时区归属、缺失日期补零及区间校验。
- 注册新路由并更新 Swagger 文档。
- 保留原有统计、授权趋势和最近授权接口，不改变旧接口响应。

### 前端改动

- 将旧六指标卡调整为有效授权、已激活设备和剩余激活名额。
- 移除仪表盘上的活跃许可证、今日新增和异常告警等旧指标。
- 增加 7 天内、8–30 天和已过期三组到期提醒。
- 增加授权码创建趋势和许可证激活趋势两张图表。
- 增加最近授权和最近激活两组记录。
- 保留“云端托管雪松授权云”文案、入口及社区版样式体系。
- 同步中文、英文和日文界面文案。

### 依赖与数据变更

- 无新增依赖。
- 无数据库结构变更和迁移脚本。

## 接口说明与测试方式

### 首页聚合

```http
GET /api/v1/dashboard/home
Authorization: Bearer <token>
```

### 业务趋势

```http
GET /api/v1/dashboard/trends?period=30d&timezone=Asia/Shanghai
Authorization: Bearer <token>
```

自定义区间示例：

```http
GET /api/v1/dashboard/trends?period=custom&start_date=2026-08-01&end_date=2026-08-31&timezone=Asia/Shanghai
Authorization: Bearer <token>
```

验证命令：

```powershell
Set-Location backend
go test ./...

Set-Location ..\frontend
pnpm run build:prod
```

## 注意事项

- 有效授权指未锁定且尚未到期的授权码。
- 已激活设备指状态为 `active` 且未删除的许可证。
- 剩余名额只汇总有效授权，单个授权的剩余值不会小于零。
- 到期提醒排除已锁定授权，三个时间区间互不重叠。
- 最近记录默认各返回 5 条；无客户授权显示为空，由前端展示“未关联客户”。
- 本次没有修改工作区已有的后端配置和前端开发环境配置。
