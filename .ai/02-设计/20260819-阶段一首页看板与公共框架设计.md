# 阶段一：首页看板与公共框架详细设计

**日期：20260819**  
**状态：已确认（20260819）**

## 一、方案概述

阶段一以“先统一框架，再升级首页”为实施顺序，覆盖登录页、公共布局、顶部导航、侧边导航、首页看板和授权管理默认入口。

本阶段不复制企业版首页业务实现，只借鉴已经稳定的页面层级、卡片组织、响应式网格和状态反馈方式。社区版继续使用当前统计概览、授权趋势和近期授权接口，不新增后端接口、数据库字段或部署配置。

整体设计原则：

1. 使用固定布局变量和响应式网格替代基于单一设计稿的视口比例缩放。
2. 页面加载、空数据和失败状态相互独立，单个区域失败不阻塞整页。
3. 所有显示内容均来自社区版真实数据或稳定的产品文案，不展示未经数据支持的宣传数字。
4. 保留现有业务动作和响应结构，入口优化不改变授权创建、激活、锁定、下载等业务规则。
5. 公共框架改动保持低耦合，避免一次性重写所有业务页面。

## 二、数据模型变更

### 2.1 数据库

无数据库表、字段、索引或迁移变更。

### 2.2 后端模型

无后端模型变更。

### 2.3 前端类型修正

近期授权类型与后端现有响应对齐：

```ts
interface RecentAuthorizationItem {
  id: string
  code: string
  customer_id: string
  customer_name: string
  description: string
  status: 'normal' | 'locked' | 'expired'
  status_display: string
  start_date: string
  end_date: string
  max_activations: number
  current_activations: number
  created_at: string
  updated_at: string
}
```

该修正只更正 TypeScript 声明，不改变服务端响应。

## 三、接口设计

### 3.1 接口变更结论

本阶段不新增、不删除、不修改后端接口。

### 3.2 现有接口复用

| 首页区域 | 现有接口 | 使用方式 |
| --- | --- | --- |
| 统计卡片 | `GET /api/v1/stats/overview` | 展示现有 6 个主指标及已有辅助指标 |
| 授权趋势 | `GET /api/v1/dashboard/authorization-trend` | 保留周、月、自定义时间范围 |
| 近期授权 | `GET /api/v1/dashboard/recent-authorizations` | 请求最近 8 条，按现有后端排序展示 |
| 登录 | `POST /api/v1/login` | 请求和响应保持不变 |

近期授权前端方法增加可选查询参数类型，以便传入现有接口已经支持的 `limit`。这不是接口扩展。

### 3.3 加载与错误策略

- 统计、趋势、近期授权分别维护加载和失败状态。
- 首次进入页面并行加载三个区域。
- 点击刷新时并行刷新三个区域，按钮显示统一刷新状态。
- 某个接口失败只在对应区域显示错误和重试，不清空其他成功数据。
- 不使用静默兜底数据冒充真实统计。

## 四、核心页面设计

### 4.1 全局布局变量

在全局主题中增加并统一使用以下布局变量：

```scss
--layout-header-height: 64px;
--layout-sidebar-width: 240px;
--layout-sidebar-collapsed-width: 64px;
--layout-content-padding: 20px;
--layout-content-gap: 16px;
--app-card-radius: 10px;
--app-card-shadow: 0 2px 10px rgba(0, 0, 0, 0.05);
```

规则：

- 不再用 `vw` 控制常规字体、圆角、内容间距和导航高度。
- 正文字号以 14px 为基线，页面标题 24px，区域标题 16px，辅助文字 12px。
- 页面内容由公共布局负责滚动，业务页面不重复计算顶部导航高度。
- 所有页面背景和卡片色继续使用现有主题变量，不开启当前隐藏的主题切换功能。

### 4.2 公共布局

结构保持“固定侧边栏 + 固定顶部导航 + 独立内容滚动区”。

#### 桌面端

- 侧边栏展开宽度 240px，折叠宽度 64px。
- 顶部导航高度 64px。
- 主内容偏移量直接引用统一变量，避免布局组件之间分别维护数值。
- 侧边栏折叠状态下，菜单使用提示文字帮助识别。

#### 平板和窄桌面

- 769px 至 1024px 默认折叠侧边栏。
- 内容区保持完整宽度，表格由页面自身处理横向查看。
- 顶部导航优先保留菜单按钮、面包屑、语言和用户入口，次要外链在空间不足时收起。

#### 手机端

- 768px 以下侧边栏使用抽屉覆盖模式，不占内容宽度。
- 点击遮罩、菜单项或关闭按钮后收起。
- 打开时锁定背景滚动，关闭后恢复。

### 4.3 侧边导航

社区版继续只显示：仪表盘、客户管理、企业线索、授权管理、发票管理、套餐管理。

- 不显示角色、用户及任何企业版菜单。
- 使用路由导航，不再依赖普通链接默认跳转行为。
- 当前路由及子路由均保持父菜单选中。
- 菜单项高度、图标尺寸、文字间距和选中态统一。
- 展开、折叠和手机抽屉使用明确但克制的过渡动画，并尊重系统减少动画设置。

### 4.4 顶部导航

- 保留侧边栏开关、面包屑、文档/GitHub 外链、语言切换和用户退出。
- 通知和主题入口继续隐藏，不以本阶段名义启用。
- 移除默认通知数字等不会显示或没有数据来源的占位状态。
- 退出登录流程及确认逻辑保持不变。
- 用户信息过长时省略显示，完整值通过提示查看。

### 4.5 登录页

登录页改为“品牌说明区 + 登录卡片”的简洁双栏结构：

- 左侧保留 Cedar-V 品牌、社区版授权管理定位和静态视觉背景。
- 移除 `10K+`、`99.9%`、`24/7` 等无社区版实时数据支持的宣传数字。
- 降低装饰动画数量；在系统要求减少动画或小屏设备上停用 Canvas 和粒子动画。
- 右侧保留语言切换、用户名、密码、记住选项和登录按钮。
- 移除当前只弹出“暂不可用”消息的忘记密码入口，不迁入企业版找回密码功能。
- “记住我”调整为只记住用户名，浏览器存储中不得保存密码。
- 兼容旧版 `loginInfo`：读取后只取用户名，并立即用不含密码的新结构覆盖；取消记住时删除记录。
- 1024px 以下隐藏左侧装饰区，登录卡片居中显示。
- 登录接口、校验规则、成功跳转和错误提示保持不变。

### 4.6 首页看板

页面结构如下：

```text
页面标题 / 简介                         最后更新时间 / 刷新

统计卡片网格：
授权码总量      活跃许可证      今日新增授权
7 天内到期      30 天内到期     异常告警

授权趋势（周 / 月 / 自定义时间）

最近授权                                      查看全部
```

#### 统计卡片

- 保留当前 6 个指标和已有辅助文案。
- 规模类使用品牌色，增长类使用中性色或正向色，风险类使用警告/危险色标识。
- 风险不能只通过颜色表达，同时保留标题和辅助说明。
- 数据加载时显示骨架，不先显示空字符串。
- 数值为 0 时正常显示 `0`，不与无数据混淆。
- 卡片本阶段不增加业务筛选动作，避免形成无对应查询能力的伪入口。

#### 授权趋势

- 保留现有周、月、自定义日期能力。
- 日期控制在桌面端位于标题右侧，小屏改为下一行并占满可用宽度。
- 图表使用确定高度：桌面 280px，平板 240px，手机 220px。
- 坐标轴标签包含在绘图区内，提示层不被卡片边界裁切。
- 无数据、失败和正常数据分别展示。

#### 最近授权

- 展示客户名称、描述、状态、到期时间和创建时间，默认 8 条。
- 移除无业务价值的页面内序号列。
- 桌面端日期列使用合理最小宽度，不再固定为 301px。
- 客户名和描述过长时省略并支持悬停查看。
- “查看全部”进入授权列表。
- 手机端优先保留客户、状态和到期时间，其余字段通过横向查看或折叠信息呈现。

#### 响应式网格

| 内容宽度 | 统计卡片 | 页面策略 |
| --- | --- | --- |
| ≥ 1200px | 3 列 | 2 行，趋势和列表全宽 |
| 768px–1199px | 2 列 | 内容自然纵向增长 |
| < 768px | 1 列 | 控件换行，表格保留核心字段 |

### 4.7 授权管理默认入口

- `/licenses` 默认进入现有全部授权列表。
- 保留 `/licenses/list`，现有书签和页面跳转继续有效。
- 原客户选择页暂保留为 `/licenses/search`，避免本阶段删除已有实现。
- 侧边导航继续指向 `/licenses`。
- 当前列表已有客户查询参数继续有效。
- 列表内可操作的客户筛选控件在阶段二统一设计和实现，不在阶段一临时拼接。

## 六、核心逻辑流程

### 6.1 首页加载

```text
进入首页
  → 并行请求统计、趋势、近期授权
  → 各区域独立进入加载态
  → 成功区域立即展示
  → 失败区域显示错误和重试
  → 全部请求结束后更新“最后更新时间”
```

### 6.2 首页刷新

```text
点击刷新
  → 防止重复点击
  → 保留现有成功内容并显示刷新状态
  → 并行重新请求三个区域
  → 分区更新结果
  → 结束后恢复按钮并更新时间
```

### 6.3 登录记住用户名

```text
进入登录页
  → 读取旧/新存储
  → 只填充用户名
  → 清除旧结构中的密码
登录成功
  → 勾选：仅保存用户名
  → 未勾选：删除记住信息
```

### 6.4 授权入口

```text
点击侧边栏“授权管理”
  → 进入 /licenses
  → 默认重定向 /licenses/list
  → 展示全部授权
```

## 七、影响范围与风险

### 7.1 公共样式影响

风险：布局变量和 Element Plus 主题可能影响后续阶段尚未改造的页面。

处理：

- 只调整稳定的基础变量和公共组件。
- 首页专属样式保持局部作用域。
- 不在本阶段全局覆盖业务表格的列宽、业务表单尺寸或页面高度。
- 对客户、授权、企业线索、发票和套餐至少完成进入、滚动和弹窗冒烟验证。

### 7.2 授权入口变化

风险：习惯先选择客户的用户会看到不同首屏。

处理：

- 原选择页保留兼容路由。
- 客户详情进入授权列表时携带的客户条件不变。
- 阶段二在列表中补齐明确的客户筛选交互。

### 7.3 登录存储兼容

风险：升级后用户不再自动填充密码。

处理：这是安全修复；首次加载即清除旧明文密码，只保留用户名，并保持登录令牌逻辑不变。

### 7.4 首页统计语义

风险：视觉分组可能被误解为统计口径变化。

处理：指标名称、数值来源和辅助文案保持现有语义，不引入企业版激活设备、产品、试用或权限口径。
